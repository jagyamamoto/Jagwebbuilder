# 素材の入れ場所

**迷ったら、ここに入れてください。** 名前も大きさも、そのままで大丈夫です。

| フォルダ | 入れるもの |
|---|---|
| `写真/` | お店・商品・人の写真。**スマホで撮ったままで構いません** |
| `ロゴ/` | ロゴや看板のデータ |
| `資料/` | メニュー表、チラシ、パンフレット、いまのホームページの文章など。**AIに読んでもらう材料**です |

写真を入れたら、AIに「素材の写真をサイトで使えるようにして」と頼むか、次を実行します。

```
npm run photos
```

写真を**サイト向けの大きさに小さくして**、`content/images/` に入れます。
このとき、**写真に埋め込まれた位置情報（撮った場所）は消えます。**
スマホの写真には自宅やお店の正確な場所が入っていることがあるので、そのまま載せないための処理です。

ここに入れたもの自体は、サイトには出ません。元の写真はこのフォルダに残ります。
